# SkillPulse

**SkillPulse** is an AI-powered platform for continuous developer evaluation that transforms real software engineering data into objective, evidence-based performance insights.

Instead of relying solely on technical interviews, coding assessments, or subjective feedback, SkillPulse continuously analyzes real GitHub repositories to evaluate developer performance based on actual production-level work.

The platform combines **code quality analysis**, **security assessment**, **requirement coverage evaluation**, **repository intelligence**, and **AI-powered insights** to provide a comprehensive view of engineering performance. It not only identifies technical weaknesses but also generates personalized learning recommendations that help developers continuously improve over time.

SkillPulse serves multiple stakeholders across the software development lifecycle:

* **Developers** receive actionable feedback, skill scores, AI-generated insights, and personalized learning plans.
* **Engineering Managers** gain continuous visibility into team performance, technical risks, and engineering KPIs.
* **Recruiters** can evaluate candidates using objective evidence collected from real software projects instead of relying only on one-time technical interviews.

---

# Project Vision

Software engineering performance cannot be accurately measured from a single interview or coding challenge.

Our vision is to replace snapshot-based evaluation with **continuous, data-driven developer intelligence**, allowing organizations to understand not only how developers perform today, but also how they improve over time.

SkillPulse bridges the gap between software quality, security, project requirements, and developer growth by transforming raw engineering data into meaningful business insights.

---

# How SkillPulse Works

1. Connect a GitHub repository through GitHub OAuth.
2. Analyze source code using SonarQube and custom AST-based analysis.
3. Perform security scanning using multiple specialized security tools.
4. Extract project requirements and evaluate requirement coverage using semantic search.
5. Calculate objective engineering KPIs and developer skill scores.
6. Generate AI-powered insights and personalized learning recommendations.
7. Present results through role-based dashboards for developers, managers, and recruiters.
